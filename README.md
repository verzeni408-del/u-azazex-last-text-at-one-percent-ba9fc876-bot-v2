The last text message a dying phone sends at one percent battery. At 1%, this phone hands its owner's bank 2FA code to the number that asked nicely, then says goodbye to the savings.

Entry for the [Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the output directory).
